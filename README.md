# Financial-analytics-power-bi
Interactive Power BI dashboard analyzing financial transactions, fees, customer segments, transaction types, and performance trends.
Novantis Capital is a fictional company  created for portfolio and demonstration purposes.

## 📊 Overview
This project is a **Power BI dashboard** designed to provide **interactive insights into transactions, customers, and risk**.  
It was built to analyze financial performance across multiple dimensions such as transaction types, customer segments, states, and yearly trends.

---

## 🚀 Features
- **Key Metrics (KPIs):**
  - Total Amount
  - Total Transactions
  - Average Transaction Value
  - Total Fees
  - Total Tax

- **Detailed Transaction Table:**
  - Transaction ID, Date, Customer Name
  - Transaction Type & Status
  - Gender, Customer Segment, State
  - Amount, Fees, Tax

- **Visualizations:**
  - Fees by Month (Line chart)
  - Fees by Transaction Status (Pie chart)
  - Fees by Customer Segment (Bar chart)
  - Fees by State (Bar chart)
  - Fees by Gender (Pie chart)
  - Transaction Type Analysis (Table)

- **Interactive Filters:**
  - Year
  - Dynamic Metric (choose KPI to analyze)
  - Occupation
  - Category

- **Drillthrough Pages:**
  - Transactions detail view

---

## 🛠️ Tech Stack
- **Power BI Desktop** for dashboard creation
- **Excel/CSV datasets** as data sources
